FAQ

How do I enable the ⚡ AI estimate?
Create an API key at console.anthropic.com, then go to Settings → AI, paste it, tap Test and Save. The ⚡ button lights up. Usage is billed by Anthropic to your own account (a few cents per hundreds of estimates).
Is the AI required?
No. You can type calories yourself; everything else works without a key.
How do I move my data to a new phone?
Settings → Backup & Restore → Export Backup → save the file (e.g. to Files or iCloud Drive). On the new phone: Settings → Backup & Restore → Import Backup → pick the file.
Why are some days missing from the calorie averages?
Days logged below 50% of your daily goal are treated as incomplete and excluded from averages. A note under the chart shows how many.

Συχνές ερωτήσεις

Πώς ενεργοποιώ την εκτίμηση ⚡ με AI;
Φτιάξε API key στο console.anthropic.com, πήγαινε Ρυθμίσεις → AI, κάνε επικόλληση, πάτα Έλεγχος και Αποθήκευση. Το ⚡ ανάβει. Η χρέωση γίνεται από την Anthropic στον δικό σου λογαριασμό (λίγα cents για εκατοντάδες εκτιμήσεις).
Χρειάζεται υποχρεωτικά το AI;
Όχι. Μπορείς να γράφεις τις θερμίδες μόνος σου· όλα τα υπόλοιπα δουλεύουν χωρίς key.
Πώς μεταφέρω τα δεδομένα μου σε νέο κινητό;
Ρυθμίσεις → Backup & Επαναφορά → Εξαγωγή Backup → αποθήκευσε το αρχείο (π.χ. στα Αρχεία ή στο iCloud Drive). Στο νέο κινητό: Ρυθμίσεις → Backup & Επαναφορά → Εισαγωγή Backup → διάλεξε το αρχείο.
Γιατί κάποιες μέρες δεν μετράνε στους μέσους όρους θερμίδων;
Μέρες με καταγραφή κάτω από το 50% του ημερήσιου στόχου θεωρούνται ελλιπείς και εξαιρούνται. Μια σημείωση κάτω από το γράφημα δείχνει πόσες είναι.
